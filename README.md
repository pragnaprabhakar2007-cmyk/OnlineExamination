# Online Examination System

## Introduction

The Online Examination System is a Java-based application
developed to conduct multiple-choice examinations digitally.
It allows students to answer questions and automatically
calculate and display their results.

## Objectives

- To conduct examinations digitally
- To provide a simple user interface
- To automatically evaluate answers
- To calculate and display the final score
- To store examination results

## Technologies Used

- Java
- Java Swing
- AWT
- File Handling

## Features

- User-friendly graphical interface
- Multiple-choice questions
- Answer selection
- Automatic score calculation
- Result display
- Result storage

## How It Works

1. Start the application.
2. Answer the multiple-choice questions.
3. Submit the examination.
4. The system evaluates the answers.
5. The final score is displayed.
6. The result is stored.
