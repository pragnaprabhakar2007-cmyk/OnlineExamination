# Online Examination System

## Introduction

The Online Examination System is a Java-based desktop application
developed to conduct multiple-choice examinations digitally.
The system provides a graphical user interface where students can
log in, answer questions, and receive their results automatically.

## Objectives

- To conduct examinations digitally
- To provide a simple and user-friendly interface
- To allow students to answer multiple-choice questions
- To automatically evaluate answers
- To calculate marks, percentage, and grade
- To save examination results for future reference

## Technologies Used

- Java
- Java Swing
- AWT
- File Handling
- ArrayList

## Features

- Student login authentication
- Multiple-choice questions
- Previous and Next question navigation
- 5-minute countdown timer
- Automatic submission when time expires
- Automatic score calculation
- Percentage calculation
- Grade calculation
- Result display
- Result storage in a text file

## How the System Works

1. The student enters the username and password.
2. After successful login, the examination begins.
3. Multiple-choice questions are displayed one at a time.
4. The student selects an answer and can move between questions.
5. A 5-minute countdown timer keeps track of the examination time.
6. The student submits the examination or it is submitted automatically
   when the time expires.
7. The system checks the selected answers.
8. Marks, percentage, and grade are calculated.
9. The final result is displayed.
10. The result is saved in `exam_results.txt`.
